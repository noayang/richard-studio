# Richard Studio

> 一个面向视觉小说 / 文字冒险游戏的**可视化编辑器**，让你**不写代码**也能做出 Ren'Py 能运行的游戏。

Richard Studio 是发布者在制作《狮心王理查》（Richard the Lionheart）同人游戏的过程中，顺手给自己打造的一件趁手工具——因此以主角之名命名。它是那部同人游戏的**副产品**，现在公开出来，**欢迎大家使用**。

---

## 这是什么

Richard Studio 是一个基于 **Electron + React + TypeScript** 的桌面编辑器，核心是「画布式 UI 编辑器 + 脚本块编辑 + 角色/资产/成就等系统管理 + 实时预览」，并**直接把你的所有改动写入项目的 `.rpy` 文件**。

你可以把它理解为：以前做文字游戏要一行行敲脚本、记语法和缩进；现在用鼠标拖一拖、点一点、填一填，就能搭出界面、写出剧情，最后直接丢给 Ren'Py 运行。

## 功能一览

### 🎨 可视化 UI 编辑器
- 画布上自由拖拽、缩放界面元素，右键插入 20+ 种组件（文本框、按钮、滑块、开关、下拉、历史记录、存档格、画廊、商店、日报面板、大地图……）
- 右侧属性面板实时调颜色、字号、圆角、透明度、背景图
- 支持多选、编组移动、锁定控件，**所见即所得**
- 每个界面有明确层级（zorder），对话框 / 变量 HUD / 地图层层分明

### 📜 脚本编辑器 · 剧情树
- 剧情组织为「章节 → 片段 → 块」的层级
- 右键插入 20+ 种指令块：对话、旁白、场景、镜头、转场、粒子、立绘、音频、视频、变量操作、条件分支、跳转、等待、漂浮文字……
- **指令模式 / 代码模式**双向切换，实时同步
- 点击某个块即可**从该块开始连续预览**整个剧情

### 👤 角色管理（头像 · 立绘 · 皮肤）
- **头像**：独立头像图，直接打开 assets 文件夹导入
- **立绘（表情）**：每个立绘一张图
- **皮肤**：依附于立绘的服装/外观变体，每套皮肤一张图
- 三类素材都可一键从 assets 文件夹导入图片
- 每个角色设专属**主题色**，对话、历史、成就里自动跟随

### 🏆 成就 · 📖 辞典 · 🔢 变量
- **成就系统**：设触发变量，满足条件自动解锁，支持隐藏未解锁条目
- **辞典系统**：专有名词词条 + 别名 + 配图，对话里点击弹释义
- **变量系统**：全局/局部，数字/字符串/布尔，可视化管理，可绑定界面实时显示

### 📅 日程系统（日期 / 天气 / 日报）
- 日期系统：从开局日期起，「结束今天」块自动加一、跨月跨年
- 天气系统：晴 / 雨 / 雪，配对应地图背景与特效
- 日报系统：每天随机生成大新闻 / 小新闻

### 🗺 大地图编辑器
- 比游戏窗口更大的可滚动地图，滚轮缩放、左键平移、边缘自动滚动
- 放置透明底 PNG 地点按钮，悬停气泡提示、点击跳转剧情
- 点击地点时，从玩家当前位置划出**带弧度的虚线**模拟移动

### 🛒 商店 · 背包 · 🖼 鉴赏
- 内置完整商店/背包逻辑：商品、价格、金币、购买、售罄、道具提升属性
- CG / 音乐 / 片段三大画廊，一键生成，配合解锁条件

### 🎲 骰子检定系统（d100）
- D&D 式技能检定：设难度阈值（DC）+ 装备加成 + 任意变量加减，掷百面骰
- 成功/失败分别跳转不同剧情，游戏内像主持人一样逐项报出数值

### 📝 合并式选择支
- 选项以「1. 选项A」「2. 选项B」形式直接排进正文，悬停变色、点击跳转，更沉浸

### ⚡ 自动写入 Ren'Py
- 你在编辑器里的**每一处改动都会自动写入项目 `game/` 目录下的 `.rpy` 文件**，无需手动复制
- 角色、界面、成就、辞典、变量、剧情、日程、地图、商店、鉴赏，全部转成标准 `.rpy`

## 快速上手（三步）

1. **新建项目** —— 打开 Richard Studio，新建项目选个文件夹，自动搭好 Ren'Py 项目骨架
2. **开始创作** —— UI 编辑器拖界面、脚本页插块、角色页配立绘，即点即存
3. **交给 Ren'Py** —— 改动已自动写入 `game/`，用 Ren'Py SDK 打开该项目即可运行你的游戏

> Richard Studio 本身是**独立桌面软件，无需 Ren'Py 也能运行**；但它输出的**成品游戏**仍需要 [Ren'Py SDK](https://www.renpy.org/) 来运行。

## 开发 / 运行

```bash
npm install
npm run dev       # 开发模式（热更新）
npm run build     # 打包产物到 out/
npm run dist      # 生成 Windows 安装包 / 便携版（electron-builder）
npm run typecheck # 类型检查
```

> 提示：若报错 `electron.app` 为 undefined，检查是否设置了环境变量
> `ELECTRON_RUN_AS_NODE=1`，取消该变量即可。

## 目录结构

```
src/
  shared/types.ts            # 共享类型与 IPC 契约
  main/                      # Electron 主进程（文件系统 / 图片选择 IPC）
  preload/                   # contextBridge 桥接
  renderer/src/
    model.ts                 # 数据模型 + 元素/块类型目录
    defaults.ts              # 默认项目
    store.tsx                # 状态管理
    components/              # 画布 / 属性面板 / 脚本 / 角色 / 场景 / 资产 / 预览
    renpy/                   # Ren'Py 导出（exportRenpy / saveProject / rpyToProject）
```

## 关于 vibe coding

Richard Studio 是 **vibe coding** 的产物——发布者本人对代码一窍不通，每一行代码都是用自然语言「说」给 AI、由 AI 代劳写出来的。

所以，如果你在使用中遇到任何问题，或者想**新增任何功能**，同样的办法也能解决：**让 Claude Code 来代劳**。你只要说清楚想要什么，它就能帮你改、帮你加。

**做游戏这件事，门槛不该是代码。** 祝大家都能做出有趣的游戏。
