# RenPy Studio

一个面向视觉小说制作的**可视化编辑器**,参考了商业级 VN 引擎「Studio」(avgplus)的交互与数据模型,核心是画布式 UI 编辑器 + 脚本块编辑 + 角色/资产 + 实时预览,并可导出 Ren'Py 代码。

## 功能

- **UI 编辑器**:画布上拖拽/缩放元素,右键插入元素(矩形/文本/按钮/滑块/对话框部件/历史记录/选项等 20+ 种),右侧属性面板实时调样式
- **竖版对话框模板**:预置「竖版对话」界面 —— 文本框靠右占 1/3、头像+角色名在文本框左侧、历史记录可滚动回看
- **脚本编辑器**:章节 → 片段 → 块,右键插入 20+ 种脚本块(对话/旁白/场景/立绘/音频/分支/变量…),**左键点击某个块 → 预览窗口从该块开始连续播放**
- **角色管理**:立绘(表情)、皮肤(服装变体)、主题色、默认站位
- **场景管理**:多层视差背景(图层 + 距离)
- **资产库**:导入图片素材、分类管理、点击应用为头像/背景
- **实时预览**:游戏屏 + 按块连续播放(场景/立绘/对白/等待)
- **导出 Ren'Py**:一键把界面 screen 或脚本转成 `.rpy` 代码

## 运行

```bash
npm install
npm run dev      # 开发模式(热更新)
npm run build    # 打包
```

> 注意:若遇到 `electron.app` 为 undefined 的报错,检查是否设置了环境变量
> `ELECTRON_RUN_AS_NODE=1`,取消该变量即可(`unset ELECTRON_RUN_AS_NODE`)。

## 目录结构

```
src/
  shared/types.ts            # 共享类型与 IPC 契约
  main/                      # Electron 主进程(文件系统/图片选择 IPC)
  preload/                   # contextBridge 桥接
  renderer/src/
    model.ts                 # 数据模型 + 元素/块类型目录
    defaults.ts              # 默认项目(含竖版对话框)
    store.tsx                # 状态管理
    components/              # Canvas/属性面板/脚本/角色/场景/资产/预览
    renpy/exportRenpy.ts     # 导出 Ren'Py 代码
```

## 参考

数据模型与元素/块类型目录提取自 `Studio-1.21.0`(avgplus),其渲染器为加密字节码,本项目的实现为独立重写。
